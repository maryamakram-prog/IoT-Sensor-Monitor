# Project Screenshots

Add screenshots here before final submission.

Recommended screenshots:

1. **Dashboard:** Show the running Flask dashboard.
2. **MongoDB collections:** Show the five collections in MongoDB Atlas or Compass. Hide connection details and credentials.
3. **CRUD test:** Show a successful API response for a temporary sensor record.
4. **Aggregation output:** Show the output from `aggregation_tests.py`.
5. **Index performance:** Show `IXSCAN`, `COLLSCAN`, and the relevant execution statistics.
6. **Geospatial query:** Add a screenshot only after a valid geospatial query has been executed successfully.

Do not include passwords, connection strings, private account information, or other secrets in screenshots.
